# БЕЗДНА — Мессенджер

## Запуск локально

```cmd
npm install
npm start
```
Открой http://localhost:3000

---

## Деплой на Render.com

### Шаг 1 — GitHub

1. Зайди на https://github.com → создай аккаунт
2. Нажми **+** → **New repository** → название `bezdna` → **Create**
3. Скачай GitHub Desktop: https://desktop.github.com
4. **File → Add local repository** → выбери папку `bezdna`
5. **Publish repository** → снять "Keep private" → **Publish**

### Шаг 2 — Render

1. https://render.com → **Sign Up** через GitHub
2. **New +** → **Web Service** → выбери репозиторий `bezdna`
3. Настройки подтянутся из render.yaml автоматически
4. Нажми **Create Web Service** → жди 2-3 минуты
5. Получишь ссылку вида `https://bezdna.onrender.com`

Отправь ссылку друзьям!

> На бесплатном тарифе сервис "засыпает" через 15 мин простоя.
> Первый запрос после сна занимает ~30 сек — это нормально.
